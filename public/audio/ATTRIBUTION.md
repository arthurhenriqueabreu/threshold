# Atribuição de Áudio — Threshold

Todos os arquivos em `public/audio/` abaixo foram **gerados proceduralmente** via script Python (`/tmp/gen_audio.py`) para este projeto acadêmico. Nenhum sample externo foi copiado.

**Licença:** CC0 1.0 Universal — Domínio Público. Livre para uso, modificação e redistribuição sem atribuição.

**Origem:** Síntese procedural (sine, noise, envelope) em `22050 Hz, mono, 16-bit PCM WAV`. Processamento leve low-pass para estética PS1.

**Arquivos:**
- `footsteps/carpet/01-08.wav` — passos carpete abafado (Level0)
- `footsteps/concrete/01-06.wav` — concreto (Level1)
- `footsteps/metal/01-06.wav` — metal (Level2)
- `entity/breathing/breath01-03.wav` — respiração entidade (positional)
- `entity/growls/growl01-04.wav` — rosnados curtos
- `entity/vanish/vanish01-03.wav` — desmaterialização
- `world/doors/open01-03.wav` — porta metal
- `world/fluorescent/flick01-02.wav` — flicker buzz
- `portal/hum.wav` — hum 36Hz loop 4s
- `phone/boot.wav, dtmf01-04.wav` — boot/tones Nokia genérico (não copia Nokia proprietário)
- `player/heartbeat.wav` — batimento 55Hz
- `ui/confirm.wav` — beep UI

**Modificações:** Trim, normalização -12dB, low-pass leve, mono.
